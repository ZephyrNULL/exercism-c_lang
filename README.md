## 📚 About

I am using the **[Exercism C Track](https://exercism.org/tracks/c)** to practice C programming through progressively challenging exercises.

Rather than only studying C theory, I am learning by solving problems and experimenting with different approaches.

The exercises help me build a stronger understanding of both fundamental and low-level C programming concepts.
